# Dungeon Tactics assets

Index of the art, sound and fonts in the project, so people and AIs know what already exists before looking for or creating something new. **Every new asset goes in here** (rule at the end of the page).

- What is in `public/` goes to the live game on each deploy; what is in `assets/` is a library for contributors and does **not** go live.
- Credit and licence of each published file: [`public/CREDITS.txt`](../public/CREDITS.txt).

## Visual identity

- **Look:** painted, in the spirit of Final Fantasy Tactics (choice of Nov 13): low-poly KayKit characters on top of terrain, trees and objects painted in our own colours (vertex colours plus a neutral brush texture), seen from above on a grid. Pixel-art style is an option of the scene (`act.pixel`, key V).
- **Colours:** FFT Classic theme (Nov 15), all in the theme block at the top of [`src/client/style.css`](../src/client/style.css): background `--bg #0a1028`, text `--fg`, highlight yellow `--focus`/`--accent #ffd75e`, hero blue `--hero`, enemy red `--enemy`, heal green `--heal`, blue HUD panels `--paper*`. Loose colours in the code are not allowed.
- **Panels and buttons:** pure CSS (`--paper*`, `--paper-frame`, `--stone`, `--trim`, `--frame` in the theme block): blue gradient, light frame, near-square corners. No image.
- **Fonts** (hosted in `public/fonts`, `@font-face` in `style.css`): **Alegreya Sans** for all text (`--font`; `--font-title` points to it since Nov 15, when Cinzel left with the FFT Classic theme). SIL OFL 1.1, licence in `public/fonts/OFL-Alegreya-Sans.txt`, Fontsource 5.3.0, latin subset, weights 400, 400 italic, 500, 700, 800.
- **3D:** low-poly from **KayKit** (flat colours with a small palette texture). A new model must be KayKit or in the same style; the `legacy-*` packs in `assets/kaykit/` are from an older KayKit phase and stand out a little.
- **Icons:** 32 px pixel-art ability icons from the theme (`public/ui/fft/`, Nov 15); game-icons.net silhouettes in a single colour (`currentColor`) for the interface symbols and as the ability fallback.
- **Sound:** short mono MP3 effects, looping `.ogg` music per place, and notes generated in code for fanfares and speech blips.

## Library (`assets/`, outside the game)

- [`assets/kaykit/`](../assets/kaykit/README.md): all the free KayKit packs (24 folders, ~125 MB, CC0): characters, weapons, dungeon, graveyard, forest, medieval hexagons, city, space base, furniture, restaurant, board, platformer, blocks, resources, tools, Christmas and extra animations on the same skeleton as the characters.
  - What each pack is, origin and licence: [`assets/kaykit/README.md`](../assets/kaykit/README.md).
  - Name of each model, folder by folder: [`assets/kaykit/INDEX.md`](../assets/kaykit/INDEX.md). Look there before asking for a new model (e.g. `torch`, `barrel`, `skull`, `tree`).
- [`assets/rpg-sounds/`](../assets/rpg-sounds/README.md): 532 RPG sound effects in `.wav` (~32 MB): spells by group, weapon projectiles and combat hits.
  - **Origin and licence not provided:** the package came without an author or licence. No sound from here goes to `public/` without first finding the origin and a free licence. Detail: [`assets/rpg-sounds/README.md`](../assets/rpg-sounds/README.md).
  - Name of each file, by category: [`assets/rpg-sounds/INDEX.md`](../assets/rpg-sounds/INDEX.md).
- To bring a model into the game: copy it to `public/models/`, trim what is unused, put the credit in `public/CREDITS.txt` and a line in the "In the game" table above.

## Rule: every new asset is indexed, explained and referenced

Applies to contributors and to every AI.

1. **Indexed:** the file gets a line on this page, in the "In the game" table if it is in `public/` or in the "Library" section if it is in `assets/`. A new pack in `assets/kaykit/` also goes into its `README.md`, and the `INDEX.md` is rebuilt with `node scripts/assets/kaykit-index.mjs`.
2. **Explained:** the line says what it is and what it is for in the game.
3. **Referenced:** the line says where the code uses the file (`file.ts`) and where it came from, with the licence; the credit goes in `public/CREDITS.txt`.
4. An asset that leaves the game leaves here too. All in the same PR as the asset.
