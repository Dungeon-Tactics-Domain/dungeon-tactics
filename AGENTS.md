# Instructions for agents

This repository's instructions live in [CLAUDE.md](CLAUDE.md): code map, commands, workflow and code rules (the decision log is in [docs/decisions.md](docs/decisions.md)). They apply to any agent (Claude Code, Codex, Cursor, Copilot) and to people. Each main folder (`src/shared`, `src/content`, `src/client`, `scripts`, `tests`) has a `CLAUDE.md` with the patterns of that area: read the one for the folder you touch.
