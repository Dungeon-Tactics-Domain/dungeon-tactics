# scripts

Applies together with the root `CLAUDE.md`.

- `battle-sim.ts`: AI against AI over N seeds (`npm run sim -- <scenario> <seeds>`). Optional: balance is decided by playing, not by the simulator.
- `smoke-game.mjs` (`npm run smoke`): serves `dist/` with `vite preview` on port 4173 and opens the title (`/`, then again with a saved expedition: Continue must show), the walkable town (`?home`, empty and with an expedition in progress: the town drawn with no window over it, then Esc opens its menu, with Continue first when an expedition is in progress), the expedition map (`?home=expedition`) and its first room with a party seeded at 9 life (the room's hero panel must show it), `?scenario=ash_wood` and a crawl boss room (`?crawl=1&boss=1`), and the free area aim (a sandbox battle on localhost: the Mage's Blast by keyboard, an arrow must move the aim one whole tile and Confirm must reach the tile choice); every URL gets `?mute=1` in headless Chrome (`PW_CHANNEL=chromium` in CI); fails on a missing screen, a console error or a failed request.
- `sandbox.mjs` (`npm run sandbox -- <spec.json | folder> [--out dir] [--sheet] [--video] [--url base]`): screenshots from scene specs (map, units, camera, hidden HUD) through its own Vite dev server and headless Chrome, one fresh context per spec on Playwright's fake clock, so the same spec gives the same picture; `--video` records the spec's `steps` in real time as WebM (+ MP4 with ffmpeg) with a `clips.json` naming the game commit; examples in `sandbox/`, gameplay clip specs in `sandbox/clips/`, looping Mechanics bench scenes in `sandbox/bench/` (served live by `npm run bench` on port 5291), format and live API in `docs/sandbox.md`.
- `crawl-sheet.ts` (`node scripts/crawl-sheet.ts <out>`): 12 crawl rooms (depths 1 to 4, three themes, one boss room) through `verifyRoom` and the sandbox's `--sheet`; each file name ends in `ok` or the number of problems, and `verifier.json` keeps them.
- `smoke.mjs`: smoke test of the static site (page, bundle, icons, one model); runs on deploy.
- `assets/`, `portraits.mjs`, `slim-character.mjs`, `lib/browser.mjs`: asset tools inherited from Warlock (icon sprite, KayKit index, portraits, animation trimming, windowless Chrome).
- `music/` (Python): `psx.py` builds a song as MIDI and renders it with fluidsynth and a SoundFont into a looping lo-fi `.ogg` (PS1 chain: sequence, small sample bank, short reverb); `test_pipeline.py` is its smoke check; `eval/` holds the blind composition eval (brief, one script per slot, `measure.py`); `stems.py` writes one `.ogg` per channel for the lab's studio; `tfg_remap.py` re-voices a General MIDI song for the Tactical Fantasy Guy font. Soundfonts and fluidsynth stay outside the repo (`MUSIC_TOOLS`, default `D:\Projetos\_musica-tools`).
- They run straight on Node, which only strips types: no `enum` and no constructor parameter properties.
