# KayKit models (every free pack)

Every free KayKit pack by Kay Lousberg ([kaylousberg.com](https://www.kaylousberg.com)): the 10 from [GitHub KayKit-Game-Assets](https://github.com/KayKit-Game-Assets) and the free (FREE) version of the ones that only exist on [itch.io](https://kaylousberg.itch.io). All **CC0** (public domain: use, change and redistribute without asking; credit is a courtesy). They live here so a model can be found without downloading anything.

- **Every model, pack by pack:** [INDEX.md](INDEX.md) (generated by `node scripts/assets/kaykit-index.mjs`).
- **Overview of all the game assets and the visual identity:** [docs/ASSETS.md](../../docs/ASSETS.md).

**This folder does not go to the live game:** only what is in `public/` is published on each deploy. To use a model:

1. Copy the file to `public/models/...` (for a `.gltf`, also the `.bin` and the `.png` texture named in its `uri` field; a `.glb` already carries everything).
2. Credit it in `public/CREDITS.txt`, in the style of the KayKit entries already there (file, pack, author, link, licence), and list the file in [docs/ASSETS.md](../../docs/ASSETS.md).
3. Cut what you do not use (animations, meshes) before publishing: every extra MB is a download for the player.

Only the glTF of each pack was copied (the `gltf` folders, unchanged), plus the textures and the licence file. In `adventurers` and `skeletons` the character textures sit next to the `.glb` even though it already embeds them: they are there for repainting. Left out: `.fbx`, `.obj`, `.dae`, Godot/Unity projects and samples. Licences read on 21/10/2026: every `LICENSE.txt` says "Creative Commons Zero, CC0"; the Holiday Bits zip has no licence, and the `LICENSE.txt` in `holiday` records the one on its page ("Creative Commons Zero v1.0 Universal").
