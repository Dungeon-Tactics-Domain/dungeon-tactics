# RPG sounds (library)

532 short sound effects in `.wav` (30.6 MB): spells, weapon projectiles and combat hits. They live here so whoever works on the sound effects can listen and choose without downloading anything.

- **Every file, by category:** [INDEX.md](INDEX.md).
- **Overview of all the game assets:** [docs/ASSETS.md](../../docs/ASSETS.md).

## Origin

- Package `freeware rpg sounds.rar`, freeware RPG sound effects.
- Added by Fernando's decision on 21/10/2026.

## How to use

**This folder does not go to the live game:** only what is in `public/` is published on each deploy.

- Before taking a sound from here to `public/sfx/`, check the asset rule in [docs/ASSETS.md](../../docs/ASSETS.md) (credit in `public/CREDITS.txt`).
- The files are as they came in the package, with the same folders and no conversion. The game uses mono MP3: convert only what goes to `public/`.
